Galeri Semua Foto

Membaca SEMUA kirim photobooth langsung dari repo GitHub — riwayat di aplikasi memang cuma tampilan ringan, tapi di GitHub setiap kirim tersimpan permanen (foto 4R + versi original + video live).

Isi username & nama repo sesuai ⚙ PENGATURAN QR di aplikasi booth, lalu tekan BUKA GALERI.

Cara paling gampang melihat semua foto

  1. Isi username + nama repo di atas (sama seperti di ⚙ PENGATURAN QR aplikasi), tekan BUKA GALERI — semua kirim foto tampil, terbaru dulu, bisa dilihat besar & diunduh satu-satu.
  2. Kalau internet booth sering mati (kirim lewat server laptop), file kirim offline itu ada di folder qr-pages/ di laptop — buka file .html-nya langsung.

Cara bagikan ke divisi PDD (paling gampang: 1 link)

  1. Buka github.com → masuk repo → Settings → General → di bawah Danger Zone pilih Change visibility → Public. (Foto event umumnya memang dibagikan antar-divisi; kalau tidak boleh publik, lihat langkah 4.)
  2. Di halaman repo tekan Add file → Upload files, seret GALERI-GITHUB.html (file ini) ke situ → Commit changes.
  3. Bagikan SATU link ini ke PDD (ganti USER dan REPO):
    https://raw.githack.com/USER/REPO/main/GALERI-GITHUB.html?u=USER&r=REPO
    PDD buka di HP/laptop mana pun — langsung kelihatan semua foto, bisa dilihat besar, diunduh, dan tombol HALAMAN LIVE membuka video fotonya. (Kalau repo sudah mengaktifkan GitHub Pages, link https://USER.github.io/REPO/GALERI-GITHUB.html?u=USER&r=REPO juga jalan.)
  4. Kalau repo harus tetap privat: PDD perlu token baca. Buat token terbatas: GitHub → Settings → Developer settings → Fine-grained tokens → pilih HANYA repo foto itu → permission Contents: Read-only → kirim token itu ke PDD (JANGAN token utama booth — token booth punya hak menulis). PDD menempelkannya di kolom TOKEN di atas, lalu BUKA GALERI.
  5. Alternatif tanpa alat: PDD juga bisa langsung buka github.com/USER/REPO — tiap kirim = 1 file puzzlecam-strip-*.html (fotonya) + 1 folder (video live-nya). Tapi galeri ini jauh lebih enak dipakai.

Urutan = jam kirim (dari nama file, waktu UTC). Tiap kartu: 4R FILTER = persis foto yang dicetak · 4R ORIGINAL = tanpa filter · HALAMAN LIVE = halaman tamu + video foto bergerak.
